# gamified-habit-tracker

## Features

- Create, edit, and delete habits, including an emoji and a short goal or note.
- Track streaks, XP, badges, and completions across the current week.
- Review a monthly completion calendar and compare this week's completions with the previous week.
- Set an optional daily reminder. Grant notification permission with **Enable reminders**; reminders are checked while the tracker is open in a browser.
- Choose the weekdays a habit repeats on and add multiple reminder times.
- Create a local profile with a display name and avatar; the profile is saved in the current browser.
- Navigate the app with a keyboard, use labeled controls and progress views with screen readers, and enable reduced motion through your system preferences.
- Choose light or dark mode.

## Run the app

For the built app, run `npm start` and open `http://localhost:3000`.

For development, run `npm start` in one terminal and `npm run dev` in another, then open the Vite URL printed by the second command.

After changing the React client, run `npm run build` to refresh the files served by Express.
